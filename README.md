# LIU’S GATE / 刘家门 — Urban Intelligence Group

第十三版。研究组正式名称为 Urban Intelligence Group（城市智能研究组）；保留 Pengyuan Liu 命名的「刘家门 / LIU’S GATE」作为网站与小城的名字。默认进入城市探索，同时保留完整的学术阅读模式。内容和城市场景分开维护；新增人员、研究、活动、成果、研究记录及属性可使用统一目录。维护入口与规则详见 [MAINTENANCE.md](MAINTENANCE.md)。本轮与参考库的比较及模型调整见 [MODEL_STUDY.md](MODEL_STUDY.md)。

## 启动

已有依赖时，在本目录运行：

```powershell
node node_modules/vinext/dist/cli.js dev --host 127.0.0.1
```

打开终端输出的本地地址（默认 `http://localhost:3000/`）。需要先安装依赖时运行 `pnpm install`。依赖版本以 `pnpm-lock.yaml` 为准，Node.js 要求 ≥ 22.13。也可使用 `pnpm dev`、`pnpm build`。

## 现有体验

- 七个建筑入口：中央 LIU’S GATE 凯旋门、市政厅、Pengyuan Liu / Yunlong Liu / Qin Li 的沿街联排住宅、研究工作室、城市档案馆。
- 北侧公共文化区、西侧花园住区、东侧研究园区和南侧档案滨水区；20 × 20 内部规划网格，外围为更大的自然岸线小岛。统一位置配置与退距规则规划住宅、北侧街屋、公共楼宇和咖啡亭；住宅地址沿街串联，出入口接入公共路网。
- 规划模式支持用地颜色叠加与街区定位；七站导览支持上一站、下一站和结束。
- 默认城市探索：点击建筑或轴测导航，镜头定位到相应地点，并在共用资料面板中阅读完整章节。点击街角公园或目录入口可以打开生活与记忆空间。
- 顶部随时切换常规阅读；当前人员或内容保持不变。资料面板可以收起，给城市留出完整画幅。手机上资料顺着页面展开，无嵌套的小型阅读滚动框。
- 浏览器后退/前进、直接链接均支持两种模式；如 `#city/pengyuan-liu` 与 `#read/pengyuan-liu`，`#city/corner-park` 为街角公园。原有建筑地址继续兼容。
- 人员均有 4:5 竖版照片位，资料面板与常规页面使用同一配置。照片放到 `public/people/`，在 `content/lab.json` 的人员记录中设置 `photo`；新增人员自动出现在两种模式中。没有照片时显示清晰占位。
- 已移除 Walk here、访客移动标记和到访状态。常驻行人随机选择目的地、靠右行走，并在路口与跟随时避让。
- 点击建筑先定位，再选择独立模型查看；外观与室内剖面可切换。屋顶随相机方向缩小停放在主体右侧；窄画布收起屋顶。镜头按实际包围体适配。外墙以几何裁切打开，不使用透明淡出或模糊滤镜。
- 模型采用完整画布分辨率，支持最多 2 倍屏幕像素密度，移除此前降采样和约 30 帧限制。屋檐、石板屋顶、排水管、窗框、烟囱帽、书架与塔吊桁架使用细尺寸几何。
- 三台可转动塔吊分别位于西北、东北、东侧的未开发地块，围挡、入口与材料堆场留在各自边界内；中心原施工点改为庭院。外围步道避开施工地块与海岸。
- 建筑采用独立轮廓：哥特钟楼、带老虎窗的浅砂岩联排端户、红砂岩凸窗中户、浅砂岩山墙端户、错层玻璃工作室、锯齿屋顶档案馆。六套室内分别为公共接待厅、起居书房、纵向工作间、明亮阅览室、开放研究工作室、档案阅览仓，包含 45 组独立家具。
- 滨水街角公园和预留纪念公告牌；公园尚无实际合影或节庆记录。保留烟囱建筑构件，移除装饰性球状烟雾。
- 公共车辆沿道路环线行驶并礼让行人；小船在南侧近海连续航行。南侧独立陆块、桥和直线驳岸已移除。
- 鼠标拖动平移；普通滚轮阅读页面，Ctrl/⌘ + 滚轮缩放模型。手机单指保留页面滚动，另有缩放、90° 旋转、恢复视角、昼夜、暂停与网格按钮。
- 画布移出视窗时暂停更新，系统减少动态效果偏好默认暂停场景动画。
- 中英文内容、键盘可用的目录、手机布局；英文模式不显示中文名称或中文切换按钮，语言切换显示 ZH / EN。浏览器不能显示三维时仍可访问内容。
- 新标志为内置图像生成工具制作的简洁平面绿色拱门，透明背景，无文字或透视。页眉、欢迎资料和网站图标共用 `public/brand/lius-gate-flat-v2.png`；提示词为同目录的 `lius-gate-flat-v2-prompt.txt`。
- 宽屏资料栏采用流动宽度；窄屏、横向短屏上下排列，长内容随页面展开。人物列表按人数与可用宽度排布，正文、链接与标题可换行。
- `#town-hall` 等地址片段可直接打开对应建筑。

- 建筑名称默认隐藏，鼠标指向建筑时才显示名称、类别、所属街区与人员单位；标签不拦截操作。拖动、离开、进入室内时收起；触屏和键盘使用目录入口，双指缩放不会误选建筑。
- 铺装按道路整体外边界生成沥青、齐平排水带、路缘石及人行道，转角与过街坡道连续衔接。只在确有高差处生成石材侧面和垫层，内部拼块不重复生成侧壁。建筑入口、公园、工地与外围步道连通；普通街景按真实底面落地，行人跟随地面高度。
- 南侧补回与主岛连续的草地，新增滨水步道及中央连接路，行人可以进入；近海船线同步外移，保留单一岛屿。
- 36 棵行道树按约 5 米的标准株距排列，入口、成熟树和过街口留空。23 棵外围树采用固定种子的自然散植；另有 9 片灌木和 7 组岩石。树池真实裁去铺装，树木切换细节时仍贴合土面。

- 三位成员住宅由同宽 1×2 单元沿街组合，正门朝向同一条步道；共享墙面处去除侧窗、屋檐和排水管突出，端户保留侧面细节。背景住宅为三户与两户组合。
- 交错石板瓦、带中脊的弯曲叶片、连续收细的分叉树枝与根、砂岩砌缝、窗格、门板、窗台花槽和细铁栏杆；花箱使用弯曲草叶与五瓣小花。住宅、背景联排、市政厅和档案馆的主要窗面采用真实开孔墙体，住宅凸窗连续支撑，薄屋面与砂岩山墙分开建模。
- 城市模块按浏览模式延迟导入，直接进入常规阅读不启动三维。概览使用轻量树冠和屋面，靠近后按投影尺寸逐个生成精细模型；最多缓存8棵近景树和3栋建筑，退远后切回概览，淘汰时释放独有几何。
- 小岛采用不规则岸线、干湿岸与水下坡面；水面使用 xi4u 的波纹法线和夜间微光算法。夜晚窗户点亮，12盏路灯有真实向下照明，中央两盏投射阴影。
- 路灯的基座与灯罩、长椅支架与接头、桌椅、电话亭窗格、汽车风挡及轮毂、船只龙骨与船舷、塔吊滑轮与吊钩均已深化。4处斑马线与路缘坡道共用位置配置。人物保留髋、膝、肩关节，步态随实际位移推进。
- 原生分辨率深度轮廓、不加放大像素或模糊。石材、板岩、木材、树皮、玻璃、金属、布料、植被及水保留不同表面响应和纹理；合批保留法线与UV，曲面共用顶点。使用ACES光照层次及单栋查看时更集中的阴影。

## 内容维护

- `content/lab.json`：人员、研究、事件及扩展属性；`content/examples/` 提供不发布的示例。
- `scripts/content.mjs`：新增、修改、删除、校验与修改前备份；详见维护说明。
- `app/content-schema.ts` / `app/lab-records.ts`：内容类型、校验及读取接口。
- `app/city-craft.ts`：石瓦、砂岩、分叉树与叶面、联排屋顶和细部构件。
- app/city-detail.ts：按投影尺寸切换细节、逐个生成、缓存和释放。
- app/city-streetcraft.ts / app/city-people.ts：街道资产和关节步态。
- app/island-footprint.ts / app/city-island.ts：单一岛屿与连续岸坡。
- app/city-water.ts / app/city-lighting.ts：动态水面和夜间路灯照明。
- app/city-materials.ts：程序化材质纹理、物理表面分类、合批与资源释放。
- `app/city-ink.ts`：保留原生分辨率的深度轮廓。
- `app/city-hover.ts`：悬停状态与标签避边定位。
- `app/city-ground.ts`：铺装裁切、标高、侧翼坡道、入口连接及非铺装承托面。
- `app/city-paving.ts` / `app/city-street-edges.ts`：道路并集边界、路缘和排水带裁切、坡道与外露分层。
- `app/city-planting-plan.ts` / `app/city-landscape.ts`：沿街株距与自然散植配置、永久树池、带枝叶的灌木及嵌地岩石。
- `scripts/check-landscape.mjs`：由物理检查调用，验证道路边界、铺装面积与挖孔、坡道侧壁、树池落地及扩建海岸。
- `app/city-layout.ts`：位置配置与完整外包络间距规则。
- `app/city-inspection.ts`：与视角及画布比例相关的屋顶停放与模型适配。
- `app/city-data.ts`：建筑位置标识、占地、建筑风格、介绍和关联关系。
- `app/city-scene.ts`：程序化三维建模、镜头、光照、模型剖切和交互。
- `app/city-plan.ts`：四个街区、步行路网、凯旋门与街景设施。
- `app/city-motion.ts`：步行图、靠右路线、行人避让、车辆环线、船只航线与碰撞工具。
- `app/page.tsx`：目录、导航、内容阅读与语言切换。
- `app/lab-content.tsx`：两种模式共用的资料、人员照片位与轴测建筑图标。
- `app/lab-navigation.ts`：内容标识、模式地址解析和阅读章节映射。
- `app/people-photos.ts`：由统一目录派生的兼容照片配置。
- `app/globals.css`：视觉主题、排版与响应式规则。
- `app/city-experience.css`：城市探索工作区、地块导航、资料面板和双模式响应式布局。
- `scripts/check-hover.mjs`：实际射线命中、标签清除、触屏与双指、不同画布比例的标签位置。
- `scripts/check-city.mjs`：建筑重叠、内容链接、三维几何与模型范围检查。
- `scripts/check-physics.mjs`：地面实际网格高度、铺装重叠/连通、河道、连续坡度和物件承托，以及真实构件几何、室内家具边界与间距、塔吊旋转范围、全部步行路径、旋转车辆占地、船只水域与栈桥、动画暂停、礼让和剖切模型检查。
- `scripts/check-navigation.mjs`：双模式内容对应、历史地址与非法地址、人员照片配置，以及画布隐藏/恢复时的相机检查。
- `scripts/check-content.mjs`：隔离目录中测试持久化增删改、备份、关联和新增内容渲染。
- `scripts/check-inspection.mjs`：各建筑在 9 种画布比例、24 个旋转角下的室内屋顶分离与适配。

目前仅使用用户提供的团队事实。成立日期、成员详细履历、研究项目与论文尚未提供，未编造内容。研究楼代表预留的研究入口，并非一个已发布的具体项目。建筑年代代表城市建筑风格，与实验室的成立时间独立。未标记的街景建筑是城市环境，不代表额外的团队成员或项目。

## 设计参考

- [xi4u / 溪间四时](https://github.com/annac777/xi4u)：三维微缩景观与像素化表现的方向参考。格拉斯哥建筑与植物独立实现；深度轮廓与水面算法参考并改写其源码，完整 MIT 许可见 THIRD_PARTY_NOTICES.md。
- [University of Glasgow — Gilbert Scott Building](https://www.gla.ac.uk/explore/visit/campustours/prospectivestudents/studentsselfguided/gilbertscottbuilding/)：哥特复兴建筑语言。
- [Glasgow City Heritage Trust — Tenement Tiles](https://www.glasgowheritage.org.uk/video-recording-cpd-understanding-and-maintaining-tenement-tiles/)：格拉斯哥红色及浅黄色砂岩住宅。

城市为格拉斯哥风格的艺术化场景，不是实地地图或历史建筑的精确复原。所有三维建筑与物件均为本项目的程序化模型。
